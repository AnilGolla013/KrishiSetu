# 🌾 KrishiSetu

**KrishiSetu** is an AI-powered agricultural platform designed to connect farmers with buyers while providing intelligent tools and essential farming services through a single web application.

### 🚀 Key Features

* 👨‍🌾 **Farmer–Buyer Marketplace** – Enables farmers to list agricultural products and connect directly with buyers.
* 🤖 **AI Crop Disease Detection** – Helps identify crop diseases and provides relevant recommendations.
* 📊 **Market Price Forecasting** – Provides insights into agricultural market prices to support better selling decisions.
* 🧠 **AI Agricultural Assistant** – Offers personalized farming guidance and recommendations.
* 💬 **Real-Time Communication** – Enables farmers and buyers to communicate through the platform.
* 🌐 **Multilingual Support** – Makes the platform more accessible to farmers from different language backgrounds.
* 🔐 **Secure Authentication** – Provides secure user registration, login, and role-based access.
* 📱 **Responsive Farmer-Friendly UI** – Designed with a simple and accessible interface for easy usage.
* 🗄️ **Scalable Backend** – Uses PostgreSQL for structured data management and Firebase for image/file storage.
